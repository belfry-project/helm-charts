# Contributing to the Belfry Helm chart

Thanks for helping. This chart is [GPL-3.0 licensed](COPYING) and accepts contributions through GitHub pull requests against `main`.

The process (issues, pull requests, commit messages, CI, code of conduct) is the same for every Belfry repository and is described in the organization's [contributing guide](https://github.com/belfry-project/.github/blob/main/CONTRIBUTING.md). No Developer Certificate of Origin sign-off is required.

- Open bugs and feature requests in the [issues of this repository](https://github.com/belfry-project/helm-charts/issues); problems with the operator itself belong in [belfry-operator](https://github.com/belfry-project/belfry-operator/issues).
- Report vulnerabilities privately, as described in the [security policy](https://github.com/belfry-project/.github/blob/main/SECURITY.md), never in a public issue.
- See [docs/contributing.md](docs/contributing.md) and the Contributing section of the [README](README.md) for working on the chart.
