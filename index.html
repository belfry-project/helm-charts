Belfry Helm charts

Helm repository for the Belfry operator. The chart version is the Belfry release it installs.

helm repo add belfry https://belfry-project.github.io/helm-charts/
helm repo update
helm install -n awx --create-namespace belfry-operator belfry/belfry-operator

Release candidates are Helm pre-releases: use helm search repo belfry --devel and --version X.Y.Z-rc.N.

Source: belfry-project/helm-charts. Index: index.yaml.
